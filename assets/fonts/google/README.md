# Bundled Google Fonts

Albumium is offline-first. The font files in this directory are packaged with
the application so themes, previews, PNG exports, and MP4 exports never need a
runtime font download.

The exact font variants were selected from the metadata shipped with
`google_fonts 6.3.3` and downloaded from the matching Google Fonts content
hashes. License copies are stored in `licenses/`: Special Elite uses the Apache
License 2.0; the remaining bundled families use the SIL Open Font License.

Sources:

- https://github.com/google/fonts
- https://github.com/google/fonts/tree/main/apache/specialelite
